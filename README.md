# WN Conseil — Projet WordPress

## URL site :
- https://wnconseil.fr/
---

## Description

WNC Conseil est un site vitrine réalisé sur WordPress, conçu pour présenter l’identité et les services de l’entreprise de manière claire, moderne et responsive.  
Le projet a été développé pour fournir une expérience utilisateur optimale sur tous les types d’écrans et assurer une gestion simple des contenus par le client.

---

## Objectifs du projet

- Développer un site fonctionnel et maintenable via WordPress  
- Mettre en valeur les services et l’activité du client  
- Assurer une navigation intuitive et structurée  
- Optimiser la performance et le SEO  
- Garantir un rendu responsive et compatible tous appareils

---

## Rôle et contributions

- Personnalisation du thème WordPress selon le cahier des charges et la charte graphique  
- Intégration complète des contenus : textes, images et médias  
- Création et structuration des pages principales et sections spécifiques  
- Mise en place de menus, formulaires et blocs dynamiques  
- Ajustements pour compatibilité responsive et performance front-end  
- Implémentation des bonnes pratiques SEO (titres, meta, structure Hn)  
- Collaboration avec le client pour validation et itérations sur le design et les fonctionnalités

---

## Technologies et outils

- WordPress (CMS) avec thème personnalisé  
- HTML5, CSS3, JavaScript pour les interactions et personnalisations front-end  
- Plugins WordPress essentiels : SEO, formulaires, sécurité, performance  
- Outils de capture d’écran pour documentation visuelle

---

## Points clés du projet

- Site entièrement administrable via WordPress  
- Navigation claire et cohérente avec hiérarchie logique des pages  
- Design adapté à l’identité du client  
- Structure et code conformes aux standards du web  
- Réalisable pour d’autres projets WordPress similaires
